## 2025-05-15 - [Image Optimization and Lazy Loading]
**Learning:** Converting high-resolution PNGs to WebP (quality 80) in this documentation-heavy repository reduced asset size by ~85% (4.9MB to 0.7MB) with no perceptible loss in quality. Combined with 'loading="lazy"' for below-the-fold images, this significantly improves the README load performance.
**Action:** Always prioritize WebP conversion and lazy loading for documentation assets to minimize repository bloat and improve user experience.
