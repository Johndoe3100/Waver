## 2025-07-15 - Asset Optimization in Restricted Environments
**Learning:** In environments where native tools like `cwebp` are missing, Python's `Pillow` library (if available or installable) is a highly effective fallback for batch image optimization.
**Action:** Always check for `Pillow` and use a one-liner Python script for bulk asset conversion to WebP quality 80 to achieve significant (~85%) size reduction.
