## 2025-07-27 - WebP Conversion and Lazy Loading Optimization
**Learning:** In documentation-heavy repositories with significant static asset weight (e.g., raw PNGs), bulk converting images to WebP format with a moderate quality level (e.g., 80) drastically reduces page payload size by ~85% with virtually zero loss in perceptual visual quality. Additionally, placing lazy loading attributes on all below-the-fold assets avoids wasteful network requests upon initial load, whereas avoiding them on top-most assets (above-the-fold) preserves Largest Contentful Paint (LCP) speed.
**Action:** Always identify original raw PNGs, convert them to WebP using Pillow, clean up the original raw assets, and configure explicit loading="lazy" attributes for below-the-fold images in documentation.
